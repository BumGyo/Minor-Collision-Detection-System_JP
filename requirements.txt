# ================================================================
# requirements.txt
# 当て逃げ・軽衝突自動検知 "Webサービス" 全体スタック (Web + Celery ワーカー + ML 推論)
# 再現・検証環境: Python 3.11.15 (Linux/WSL2, CPU 推論)
#
# 本ファイルはサービス実行用 (CPU) です。GPU学習環境は別途管理してください。
# Python 3.12+/3.14 は torch ホイール未提供の可能性があるため Python 3.11 環境を推奨します。
# ================================================================
#
# -- Web サービス実行に必要なプロジェクト構成 -------------------------
#   capstone-26/
#   ├── backend/           [必須] FastAPI Web + Celery ワーカー
#   ├── model/             [必須] 推論コード
#   ├── weights/           [必須] 学習済み重み
#   ├── ui/                [必須] フロントエンドソース
#   ├── docker-compose.yml [選択] ローカル MySQL + Redis 起動(外部DB使用時はRedisのみ)
#   └── requirements.txt   [必須] Python 3.11 環境構築用
#
#   自動/ローカル生成項目:
#   - storage/             アップロード元動画/CAMクリップ
#   - venv311/             Python 3.11 仮想環境
#   - ui/node_modules/     npm install により生成
#
# 実行前提: Docker, Node.js(+npm), uv (または python3.11) がインストールされていること。
#
# -- 初回実行手順 ------------------------------------------------
#   docker compose up -d db redis   (外部PostgreSQL使用時はredisのみ)
#   uv venv --python 3.11 venv311
#   uv pip install --python venv311 -r requirements.txt
#   uv pip install --python venv311 \
#       --index-url https://download.pytorch.org/whl/cpu torch==2.12.0 torchvision==0.27.0
#   cd backend && ../venv311/bin/python -m uvicorn app.main:app --port 8000
#   cd backend && ../venv311/bin/celery -A app.worker worker --concurrency=1
#     (サービスバックボーンは model/ の x3d。ローカルに "s3d model/" があれば MODEL_VARIANT=s3d に変更可能)
#   cd ui && npm install && npm run dev
#
# torch/torchvision は PyTorch 専用インデックスから取得するため別ステップでインストールします。
# PyPI 一般パッケージとインデックスが異なるため1つの requirements に混在させると uv インデックスポリシーと衝突する可能性があります。
#
# -- 通常の venv/pip 使用時 ---------------------------------------
#   python3.11 -m venv venv311 && source venv311/bin/activate
#   pip install -r requirements.txt
#   pip install --index-url https://download.pytorch.org/whl/cpu torch==2.12.0 torchvision==0.27.0
#
# macOS: 上記の torch コマンドをそのまま使用可能(MacはCPUホイールが標準)。
# GPU(CUDA)で推論する場合は --index-url を https://download.pytorch.org/whl/cu126 (または cu130) に変更してください
# (torch 2.12.0 は cu126・cu130 版のみ存在)。サーバーデプロイ手順は deploy/DEPLOY.md。
# サービスバックボーンフォルダ(model/)の config.py は INFER_DEVICE_TYPE="cuda" のため GPU があれば
# そのまま使用し、なければ警告を出力してCPUへ自動切り替え。
# ================================================================
