# ================================================================
# requirements-train.txt
# 当て逃げ・軽衝突検知 "モデル学習 · 推論" 専用 Python 環境 (model/ = x3d-m)
# 再現・検証環境: Python 3.11.15 (ローカル CPU) / Python 3.10 (学習サーバー GPU, RTX 3080)
#
# 本ファイルは ML コード(train / predict / eval)のみを実行するための最小依存関係です。
# Web サービス(FastAPI・Celery・MySQL・Redis)は含みません → ルートの requirements.txt を使用。
# ================================================================
#
# -- ファイルの用途 -----------------------------------------
#   サービス・学習モデルは model/(x3d-m) であり、そのディレクトリ内で実行します。
#   (以前の s3d バックボーンは "s3d model/" へ移動し git から除外。slowfast model/ は未使用)
#     (cd model && PRETRAINED=1 python3 -u main.py --mode train)    # 学習
#     (cd model && EVAL_WEIGHTS=../weights/<ファイル> python3 -u main.py --mode eval)
#     (cd model && python3 -u main.py --mode predict)                      # 単一動画 CAM
#     (cd model && python3 ../check_probs.py ../weights/<ファイル>)            # 検証セット確率分布
#     (cd model && python3 trainplot.py ../outputs/trainlogs/*.csv)        # 学習曲線グラフ
#   ※ パイプ(| tee)でログを出力する際は -u を付与してバッファリングを無効化してください。
#
# -- 学習サーバー準備: tmux (システムパッケージ — pip ではありません) --------------
#   学習には数時間要するため、SSH 切断時にシェル上のプロセスが停止するのを防止します。
#   tmux セッション内で実行することで接続が切れても学習は継続し、後から再アタッチ可能です。
#     sudo apt install tmux
#     tmux new -s train          # セッションを作成し学習コマンドを実行
#     Ctrl+b を押した後に d        # セッションからデタッチ (学習は継続)
#     tmux attach -t train       # 再アタッチして進捗確認
#     tmux ls                    # セッション一覧
#
# -- torch / torchvision は以下の別ステップでインストール ----------------
#   PyTorch 専用インデックスから取得するため本ファイルには記載しません。
#   (PyPIとインデックスが異なるため1ファイルに混在させると uv インデックスポリシーと衝突可能)
#
#   ※ バージョンを固定せず各 CUDA インデックスが提供する最新ペアのインストールを推奨。
#     PyTorch は古い CUDA ビルドの提供を順次終了するため、特定バージョンが存在しない場合があります。
#     (例: cu121 インデックスは torch 2.5.1 まで提供 → 2.12.0 はインストール不可)
#     本プロジェクトのコードは torch 2.5.1 以上で正常動作します(S3D・AMP・channels_last)。
#
#   • 学習(GPU/CUDA): サーバーのドライバが対応する CUDA に合わせたインデックスを選択
#       (nvidia-smi の 'CUDA Version' 確認 → cu121 / cu124 / cu126 / cu128 …)
#       pip install --index-url https://download.pytorch.org/whl/cu121 torch torchvision
#     → torch·torchvision ペアは pip が自動解決 (cu121なら 2.5.1 + 0.20.1)
#     → config.py の TRAIN_DEVICE_TYPE="cuda"
#
#   • 推論(CPU, サービス/ローカル検証):
#       pip install --index-url https://download.pytorch.org/whl/cpu torch torchvision
#     → config.py の INFER_DEVICE_TYPE は "cuda" ですが、GPU がなければ
#       警告を出力して自動的に CPU へフォールバックするため設定変更は不要です。
#     (ローカル検証時の実インストール: torch 2.12.0+cpu / torchvision 0.27.0+cpu)
#
# -- インストール手順 (ローカル、CPU 推論基準) -------------------------------
#   uv venv --python 3.11 venv311
#   uv pip install --python venv311 -r requirements-train.txt
#   uv pip install --python venv311 \
#       --index-url https://download.pytorch.org/whl/cpu torch==2.12.0 torchvision==0.27.0
#
#   (通常の venv/pip)
#   python3.11 -m venv venv311 && source venv311/bin/activate
#   pip install -r requirements-train.txt
#   pip install --index-url https://download.pytorch.org/whl/cpu torch torchvision
# ================================================================

# ---- 画像処理 / 数値計算 (dataset·inference·evaluate) ----
